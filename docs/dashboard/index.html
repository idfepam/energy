Research question 1

RQ1 — One Europe-wide mode, or many?

How much of European price co-movement is a single Europe-wide mode, how much is cluster-specific, and how many cluster dimensions are statistically supported? We eigen-decompose the hourly zone correlation matrix and test each eigenvalue against phase-randomised surrogates — panels with each zone’s own autocorrelation preserved but all cross-zone coupling destroyed.

Research question 2

RQ2 — Do the clusters survive the calendar?

Do the price clusters persist across seasons and intraday, or does the partition reorganise? Each stratum is clustered on its own correlation matrix (market mode removed) and scored against the full-year partition with the Adjusted Rand Index. The bar to clear is not ARI = 1: it is a permutation null of the same sample size, because a shorter window alone lowers ARI.

Research question 3

RQ3 — Does price follow the wires?

Does price co-movement follow the physical interconnection topology, and where does it diverge? We measure correlation against hop distance in the interconnection graph, test the whole distance matrix with a Mantel permutation test, and then name the borders that break the pattern in each direction.
